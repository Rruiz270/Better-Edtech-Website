# Better Tech - Website Rebuild

A modern, responsive rebuild of the Better Tech website showcasing AI-driven educational solutions.

## Features

- **Modern Design**: Clean, professional interface with gradient backgrounds and smooth animations
- **Responsive Layout**: Fully responsive design that works on all devices
- **Interactive Components**: Hover effects, smooth scrolling navigation, and dynamic content
- **Performance Optimized**: Built with Next.js and Tailwind CSS for optimal performance

## Tech Stack

- **Framework**: Next.js 14
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Language**: TypeScript

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) to view the website.

## Deployment

The website is configured for static export and can be deployed to Vercel, Netlify, or any static hosting service:

```bash
npm run build
```

## Sections

- **Hero**: Main landing section with call-to-action
- **Partnerships**: Interactive cards showcasing strategic partnerships
- **Success Cases**: Detailed case studies with metrics and results
- **Footer**: Contact information and quick links
